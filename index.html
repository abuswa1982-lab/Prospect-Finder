Prospect Finder

Feed it a customer category and a ZIP code or city, and it searches Google Maps for businesses matching that profile in that area. Built as the sourcing half of the CRM classifier pair — the classifier tells you which industries are your best customers, this finds more of them.

Held in memory only for this session, never saved. Re-paste each time you open the tool. In Google Cloud Console, enable "Places API (New)" specifically, not the older "Places API" (new projects can no longer turn that one on). Restrict the key to this page's URL as an HTTP referrer, not by IP.

Each search (one ZIP or one city) is one billed Google request, whether it finds 2 businesses or 20. Including phone/website bumps the rate slightly but it's still one request. Google's current published rates run roughly $32 per 1,000 searches for name/address (first 5,000/month free), or $35 per 1,000 with phone/website included (first 1,000/month free). The session cap above is a hard stop: once you hit it, the tool refuses to search again until you raise the number or reload the page.
